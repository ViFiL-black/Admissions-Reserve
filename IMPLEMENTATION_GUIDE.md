## Потенциальные проблемы и решения

### Проблема: Foreign Key Constraint Error
**Причина:** Попытка удалить абитуриента с существующими связанными записями
**Решение:** Используется ON DELETE CASCADE в определении таблиц

### Проблема: SessionManager.CurrentApplicantId is NULL
**Причина:**页面открыта без выбранного абитуриента
**Решение:** Проверять SessionManager перед операциями с БД

### Проблема: Данные не загружаются при открытии страницы
**Причина:** LoadFromDatabase() не вызывается в конструкторе
**Решение:** Добавить вызов в конструктор или в обработчик события Loaded
